# PNMRemote downloads

This repository distributes official PNMRemote application builds and signed update feeds.
The PNMRemote application source code is not hosted in this repository.

Download available builds from [Releases](https://github.com/Glym143/PNMRemote/releases).
Release notes describe the supported platforms and installation method for each build.

## Updates

Compatible app versions check the signed update feed and verify downloaded files before installation.

## Repository contents

The Git tree contains only this download information. Application packages and update manifests
are attached to Releases. GitHub's automatic “Source code” archives therefore contain only
this repository's download information, not the PNMRemote application source.
